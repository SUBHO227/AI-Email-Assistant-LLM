# AI-Powered Email Autocomplete Assistant

An AI-powered email autocomplete system developed using Generative AI technologies.

## Technologies Used
- Python
- Flask API
- Ollama
- Gemma 2B
- CustomTkinter
- Speech Recognition

## Features
- AI-based email sentence completion
- Voice input support
- Local LLM execution
- GUI-based desktop application

## System Workflow
User Input → Flask API → Ollama → Gemma 2B → Generated Output

## Future Scope
- Tone selection
- Multiple suggestions
- Web/mobile integration
- Cloud deployment
